Clikd

Clikd is a desktop + mobile gaming communication app
that connects players with their communities.

Role

UX/UI Designer
Prototyping & Testing

Tools

Figma
Figjam

Process


Focusing on one feature at a time, I started with a userflow for that feature to quickly explore the users path and determine what pages were neccessary for that feature. I then designed lofi prototypes for the feature, shared with the team, recived feedback and either made adjustments or moved on to hifi, prototyping, and testing. Working mobile first and adapting to desktop proved.

Assumptions

  • Users need to easily find people play with. A real time, filterable feed of gaming groups will increase active users
  • Users will then need to communicate effectivly within gaming sessions and one-on-one
  • Users need to be able to form groups. Recurring game sessions and group chats will increase user retention
  • Users will want to access different features at the same time (e.g. scroll feed while waiting for a game to start or search for sessions while chatting with friends) therefore making the desktop features modular will provide the easiest mode of use - whereas on mobile, all features are easily accessable through the nav bar and should hold previous location.

Flare

The first solution is "flare," users signal they're looking for teammates, and the system matches them with compatible players based on game, rank, role, region, trust, and social proximity. requirements are:

  • Browse posts
  • Filter according to user needs
  • Create and join gaming sessions
  • Seamlessly move into voice chat

Drop

The next solution is

  • Voice and video calling
  • Group and one-on-one
  • Accesible from several start points
